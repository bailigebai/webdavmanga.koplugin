# KOReader WebDAV 漫画插件

当前源码：**0.4.13，2026-10-03 OPDS 章节点击修复包**。修复点击章节后被菜单返回动作取消的问题，保留“插件售价50元”提示。使用说明见[插件说明](webdavmanga.koplugin/README.md)，验收证据见[验证记录](docs/verification.md)。

通过 WebDAV、OPDS 和本地文件进入漫画书架与阅读器，支持图片型 EPUB、受限图片型 PDF、ZIP/CBZ、RAR/CBR、7Z/CB7、TAR/CBT 等容器。具体格式与设备限制见 [插件说明](webdavmanga.koplugin/README.md)。

## 安装

下载 [最新安装 ZIP](releases/webdavmanga.koplugin-v0.4.13-20261003-opds-chapter-open.zip)，解压后把 `webdavmanga.koplugin` 文件夹放入 KOReader 的 `plugins/` 目录，再完全退出并重启 KOReader。覆盖前备份原插件；账号和服务器地址在设备的插件设置中填写。

## 本次重构：智能分格阅读

默认引擎开启智能分格后整页长按进入。框线排序与对白保护范围分开；点按分格中间打开控制，在保留周边、独立格、自由视图间切换，选择0°/90°/180°/270°旋转、左右/上下导航、操作反向和分格阅读顺序。自由视图缩放拖动时不翻页；退出分格恢复原页。点按设置应用本书，长按同时作为新书默认值，漫画阅读说明中有完整操作。

参考Meguru的交互和Panels+的MIT检测、排序；不新增原生依赖或独立阅读器。真实图片抽查修复细白缝合并，但相连格、斜格、无框和复杂嵌套可能仍显示完整单页，不能保证自动精准。设备触摸和墨水屏效果待真机验收。

## 已支持：对白气泡放大与阅读说明

在“漫画阅读设置 → 图片显示”开启“气泡放大”。默认使用单指长按，识别封闭浅色对白区域并在原页上浮层放大；松开后保留，点一下或滑动关闭。提供1.5、2、3倍和可选点按触发，空间不足时完整适屏。默认关闭，既有双指象限手势保留，已进入的分格操作不变。

“关于 → 漫画阅读说明”和阅读设置中的同名入口提供可滚动中文说明，包含翻页、双指象限、气泡放大及限制。检测使用当前显示图片，采样最多256×256，不重新下载、解码或写阅读进度。

参考 [BubbleZoom](https://github.com/anezih/bubblezoom.koplugin) 的核心对白缩放行为独立实现。未移植OCR、翻译、形状蒙版或扫描算法切换；其离线翻译不支持当前Kindle。检测为启发式：空对白、开放轮廓、过小或黑底区域可能失败，复杂闭合字形也可能误选，建议按对白空白处。实际触摸、耗时与墨水屏显示待设备验收。

## 已支持：双指按住临时放大

漫画页上两指同时按住约半秒，双指中心点所在的左上、右上、左下或右下象限会放大；松开任一指恢复原画面、显示位置和先前已锁定的象限。按住期间移动不改变所选象限。原双指点按操作保留；加载、设置及分格界面不会触发。

该功能仅修改阅读器和手势接收层，复用当前图片，不下载、不重新解码、不写阅读进度。参考 leadingmangazoom 和 maximum 的象限行为独立实现，没有移植其他功能。详情和验证证据见 [验证记录](docs/verification.md)。Kindle 触摸实测尚未确认。

## 当前修复

- OPDS 章节菜单显式处理行选择，避免 KOReader 默认选行后调用关闭回调，退回上一级并取消章节打开。直接章节和异步详情都保留续读选择；主动返回、取消和过期事件仍受导航保护。设备实际菜单方法和生产界面适配器有回归验证，真实阅读显示待设备验收。
- OPDS 目录请求先等待 KOReader 联网；后台失败、证书、超时、连接被拒绝及响应过大分别提示，并记录固定类别。关闭目录后旧联网回调不再启动请求。10月3日本机 Suwayomi 启动失败恢复后，两个保存地址返回200并解析出9条根目录；用户确认漫画和章节列表可以打开。
- 图片显示新增可选“长条连续”：跨相邻图片合成当前屏幕、白/黑/自动背景、智能空白带翻屏、重叠、适高与左右留白；保存长图内的位置。切换模式使旧请求失效，退出象限和分格状态，失败保留已显示画面。
- EPUB：同一封面出现多次时保留阅读页序并使用独立缓存编号。
- PDF/RAR：在能够核对当前连接归属时恢复缺少旧标记的起始页缓存；归属冲突和并发变化仍拒绝。
- RAR：前三页验证后开始阅读，后台继续目录，减少首屏请求次数。
- KindleHF 7Z：核心缺少 LZMA 时使用插件自带的固定版本官方解码库。
- OPDS：按完整路由识别 Suwayomi 的 `/api/opds/v1.2`，避免其中的短路径被误判为 Kavita 或 Komga。章节详情保持所属系列身份，保存地址时保留协议版本及有界语言标签。同步进度冲突保留本地/远程选择，真正的服务信息冲突仍拒绝；自动识别和显式 Suwayomi 都有协议回归测试。

## 开发与验证

需要 Python 3.11 或以上；Lua 5.1 测试运行时由 `lupa` 提供。在仓库根目录执行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe scripts/run_lua_specs.py --all --syntax-root webdavmanga.koplugin
.venv\Scripts\python.exe scripts/package_plugin.py
```

Linux/macOS 将 Python 路径改为 `.venv/bin/python`。打包输出在 `dist/`，文件清单、敏感内容、原生库哈希和双次构建一致性会自动校验。`releases/` 保留已交付设备的安装 ZIP；后续源码变更须同步提供新包。

## 验收与限制

本地测试不能替代真实 WebDAV/OPDS 服务器和 Kindle 的界面验收。先确认 Suwayomi 服务已启动、电脑浏览器可以打开同一个 OPDS 地址，再完全退出并重启 KOReader，打开连接后刷新目录，选择系列、章节，检查首张和连续翻页。在“漫画阅读设置 → 图片显示”选择“长条连续”，检查跨图翻屏、返回、继续阅读及切回整页。RAR/OPDS 最近修复及长条墨水屏显示仍待实机验收。

长条模式保留最多两张解码图片，仅合成当前屏幕和最多15%的适高探测区。单张解码目标有像素上限；极长图可能变模糊，原生解码器的临时内存峰值未在设备测量。一屏超过64个极短图片片段时会明确失败并保留旧画面。

固实 7Z 后续页面可能反复解码压缩前缀，流量和速度取决于文件结构。任意复杂、加密或损坏 PDF/归档并非都支持；整本下载需要明确确认。授权服务部署和私有签名材料不包含在本项目。
