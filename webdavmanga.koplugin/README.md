### v0.4.27：页面自动裁剪增强

页面自动裁剪增强
在“漫画阅读设置 → 裁切白边”同时开启“自动裁白边”和“页面自动裁剪增强”。增强是独立算法选项，默认关闭；关闭自动裁白边总开关后，增强不运行。关闭增强则恢复原自动裁白边算法。不会改变去灰、亮度、对比度或分格开关，也不会单独显示“处理图像成功”。

阅读指针默认位于 KOReader 数据目录下的 `webdavmanga-streams/<服务器 [身份后缀]>/<系列 [身份后缀]>/<章节>.meguru`。在“WebDAV 漫画 → 连接设置 → OPDS 指针与封面”可修改绝对根目录、切换“按服务器建立子目录”和“保存系列封面”。关闭封面保存只影响以后捕获，不删除已有 `.cover.jpg`；修改目录设置不移动旧指针，已有书架记录仍复用原路径。系列目录使用来源与系列稳定 ID 隔离，同名系列及不同来源不会共用封面；名称变更时仅检查当前目录层，不递归扫描整个根目录。指针只保存稳定身份、页数及脱敏后的流地址等元数据；新目录观测会原子更新已有指针，并保留服务器进度高水位。实际请求从当前连接取得凭据。

多个写入同时发生时，后来的请求提示“正在保存”，稍后重新选择章节即可重试；正常完成和失败都会释放本次持有的空锁目录。异常断电或强制终止进程可能遗留系列目录内的 `.meguru-publish.lock`。请先完全退出所有访问此目录的 KOReader 实例，确认没有设备仍在写入，再只移除确认遗留的空锁目录；不要删除 `.meguru` 或封面。插件不会按时间猜测锁已过期并自动删除。

正文只存在于 HTTP 响应和有界内存页缓冲，不写图片、压缩包、正文 `.part`、spool 或 building 文件。允许持久化的阅读内容是 `.meguru` 元数据和启用封面时的单份 `<系列目录>/.cover.jpg`；原有设置、Library 和 Progress 继续保存各自元数据。封面按书封面、系列封面、第一页顺序尝试，验证成功后才发布，短暂原子写入文件不作为正文缓存。

历史、分类、评分和缓存视图读取同一 Library/Progress 身份，按原 `pointer_path` 精确重开章节，共用同一系列封面。缓存视图中的 OPDS 条目仅代表指针与封面，正文显示 0/未离线，不提供整本缓存删除；退出后不能把它当作离线漫画。没有第二份 OPDS 记录表或跨会话正文页清单。

- 点击 MOBI、PDF 等漫画书籍后立即显示当前文件名和打开进度条，不再在后台分析时表现为“点击无反应”。
- 图片型 MOBI 索引阶段使用 64 KiB Range 块，与图片头探测窗口一致；常见页面由最多约 8 次请求降为 1～2 次请求，减少高延迟 WebDAV 下的等待。
- 首张和后续 MOBI 图片页使用 256 KiB Range 块，保留 64 KiB 顺序落盘，降低大图首次显示和翻页时的 HTTP 往返次数。
- MOBI 无法按图片流式索引并回退完整下载时，进度条按 `.part` 文件实际写入字节每 0.5 秒更新；成功、失败或同步拒绝都会关闭进度层。
- 本版没有把半下载的 MOBI 交给 KOReader。Range 失败时仍保留完整下载校验和原生阅读器回退，避免损坏文件导致闪退。

## 0.3.67 流式 MOBI 历史封面与兼容性修复

- 流式 MOBI 阅读历史会保留首图的 Range 元数据；历史封面在页面缓存被清理后仍可重新提取，不会把 `book.mobi#mobi/N` 当作普通 WebDAV 图片路径。
- 封面服务允许 `mobi_images` 历史记录，并复用现有页面提取缓存，避免重复下载整本 MOBI。
- MOBI 图片索引遇到超大 JPEG APP/EXIF 头时会按需扩大探测窗口（最多 256 KiB），减少合法页面被误判为损坏。
- 远程 MOBI 的流式索引或 Range 读取失败时自动回退到已验证的完整文档缓存和 KOReader 原生阅读器；失败提示会明确标识 MOBI/Range 阶段。
- MOBI 头表、资源记录和页面提取的 Range 失败会保留具体阶段，不再统一伪装成普通图片损坏。

## 0.3.66 MOBI 远程打开与翻页稳定性

- 远程 MOBI 的 PalmDB 图片索引改在后台任务扫描，点击文件后不会阻塞 KOReader 主界面。
- 索引跨后台进程只传递纯页面数据，并为大章节保留 1 MiB 结果空间，避免大 MOBI 因默认消息上限打开失败。
- MOBI 页面提取在后台按文件路径重新建立 HTTP Range 流，不再复用前台进程的读取闭包，降低连续翻页后出现“文件不完整或无法解码”的概率。
- 索引扫描使用 8 KiB 元数据块，页面读取继续使用 64 KiB 块；Range 长度和 Content-Range 仍严格校验。

## 0.3.65 第五期 A：按需流式阅读

- 本版插件需要配套的 KOReader MuPDF 流式补丁才能对 PDF/CBZ 等文档真正免整本下载；标准 KOReader 5.19.5 会自动走完整缓存回退。

- 开关关闭时预览只提示“去灰增强已关闭”，不会读取样本或解码处理。修改预设或参数不会自动打开总开关，需要手动开启才应用。

安装方法同下方：完全退出 KOReader 后覆盖插件文件夹，再启动。无需删除设置、缓存或漫画；本包不修改 KOReader 本体。

本版已经通过电脑端开关行为和真实 KOReader 图像缓冲测试；Kindle 实机触控、内存与翻页耗时尚未验证。

## 蓝牙手柄

本插件兼容 `kindle-hid-passthrough` 的两种输出：KOReader 原生页键（`RPgFwd`、`LPgFwd`、`RPgBack`、`LPgBack`）以及 HID 插件映射的 `GotoViewRel` 事件。进入漫画阅读后，下一页、上一页和返回分别使用这些标准动作；不需要修改 WebDAV 连接设置。若手柄仍无响应，请在 HID Passthrough 的按键映射中将两个按键分别绑定到 KOReader 的“Next page”和“Previous page”，并确认设备模式为“KOReader only”或未被 Button Mapper 独占。

## 配置连接、根目录与书架路径

在“WebDAV 漫画 → 连接设置”中可以添加多个来源。你可以明确选择“普通 WebDAV 直连”（适合在家或局域网内使用），也可以选择“添加节点小宝 TCP 组网”（适合已经接入节点小宝网络后访问家中 NAS）；连接列表会标出当前来源类型，点选任一来源即可切换，插件不会强制使用节点小宝。普通 WebDAV 来源填写服务器地址、用户名、密码和 **WebDAV 根目录**，先点“测试”，显示“连接成功”后再保存。可使用文档示例 `https://nas.example/dav`；请以自己的服务地址为准，勿在截图或日志中公开凭据。切换来源后，书架、目录缓存和图片缓存按来源身份隔离。

如果漫画已经放在 Kindle 本机，选择“添加 Kindle 本地目录”，填写 Kindle 上的绝对路径（例如 `/mnt/us/Comics`），测试通过后保存。此来源不需要服务器、用户名或密码；插件只允许访问你配置的目录及其两级子目录，会拒绝越界路径和符号链接。通过 USB 复制漫画后，重新打开书架或点“刷新”即可看到新内容。

**书架自定义路径**由 WebDAV 根目录确定：如果只想让插件从某个漫画目录开始浏览，就把该目录设为根目录（例如 `/Comics`）；根目录之外不可进入。书架会记住根目录内上次浏览的位置，之后可继续逐级进入。服务器地址或去除首尾空白后的用户名发生变化时，书架位置重置到新根目录。仅更改 WebDAV 根目录时，若旧书架位置仍在新根目录内则保留；只有位于新根目录外才重置。这样可避免混用不同连接的本地状态。

HTTPS 使用 KOReader 的证书链和主机名校验。私有 CA 或自签名环境可将已核验的 PEM CA 文件保存为 `koreader/settings/webdavmanga-ca.crt` 并重启；不要通过关闭证书校验绕过错误。

## 节点小宝 TCP 组网

节点小宝官方确认异地组网是透明 TCP 网络，不会修改 WebDAV 请求或图片数据，也没有让本插件登录账号、读取设备或创建隧道的服务器接口。因此，节点小宝客户端或小宝网关必须先在插件之外配置完成，使 Kindle 能够访问 NAS 的组网 IP。仅在手机上扫码登录节点小宝，不能自动让 Kindle 加入该虚拟网络。

准备好组网后，打开“连接设置 → 添加节点小宝 TCP 组网”，填写完整的组网 WebDAV 地址，例如 `http://100.64.1.2:5005`，再填写 WebDAV 用户名、密码和漫画根目录。点“测试”时插件先检查地址中的 TCP 主机和端口；端口可达后，再原样发送标准 WebDAV `PROPFIND`。两步均成功才会显示“TCP 组网与 WebDAV 连接均成功”。这里的端口是 NAS 实际 WebDAV 端口，并非插件固定端口。

KPW6 不能仅靠本插件获得节点小宝路由。可用前提有三种：Kindle 上已有兼容的节点小宝客户端；Kindle 所连接的路由器或同网设备已配置小宝网关；或者节点小宝已经提供一个能从 Kindle 当前网络直接连接的 TCP 地址。本版不捆绑官方 ARM 客户端，因为其安装脚本需要 root 以及常规 Linux/OpenWrt 服务环境，尚未证明与 KPW6 固件、虚拟网卡和启动流程兼容。

从 0.3.20 或更早版本升级不会删除旧连接。旧节点小宝地址如果已经失效，在连接列表点选该来源，再点“编辑当前连接”，换成实际可达的组网 WebDAV 地址并测试保存；保存后只保留 TCP 主机、端口和协议信息，不保存节点小宝账号或登录会话。

## 浏览、进入漫画与支持格式

书架目录每行都有两个操作：点目录名称进入下一级；点右侧“进入漫画”识别当前目录。当前目录只要直接包含任意文件（图片、PDF、MOBI 或未知后缀），书架就会显示固定的“当前文件夹 → 进入漫画”操作，不再用扩展名把目录挡住。图片漫画可以是“图片直接位于漫画目录”，也可以是“漫画目录 → 章节目录 → 图片”；图片目录不递归到更深层。PDF、MOBI 等已知文档作为文档项交给 KOReader 原生引擎处理；未知后缀会显示为不支持格式，但不会阻止进入目录。文件和文件夹按自然数字顺序排列。

图片目录支持：**JPG/JPEG、PNG、WebP、GIF（仅静态首帧）、TIF/TIFF、SVG**。原生文档支持：**PDF、MOBI、AZW、EPUB、CBZ、CBR、DJVU/DJV、FB2、PDB、PRC**。**BMP、AVIF、HEIC 和动画播放均不受支持**；GIF 只解码并显示静态首帧，不播放动画。CBZ/CBR 在目录中作为文档交给 KOReader 原生引擎，不在当前图片 Reader 内解压。无法识别、下载或解码的页面会提示失败，缓存副本会被清理，可重试、跳过或返回。

## 阅读、历史与离线状态

- 阅读设置中，`normal / manga` 分别是普通和日漫反向翻页；阅读页不再显示左上角页数或默认悬浮关闭按钮，只保留顶部 2 像素进度线（可关闭）。右上角双击后才显示最上层的大号“返回漫画”按钮。点屏幕中间打开两级、每行两格的控制菜单；“返回漫画列表”位于“图片显示”中整页/适宽按钮的下一行。双击仍可切换整页/适宽，加载页、错误页和 Kindle 物理返回键可直接退出。
- 0.3.76 保留“漫画去灰增强”，并新增独立的“亮度与对比度”；两者都在预加载阶段合并处理，均可完全关闭。旧版高开销色阶、曲线和实时逐像素滤镜仍不恢复。主菜单“前光与色温”调用 KOReader 的设备接口，KPW6 前光按设备实际范围（通常 0–24）校验，色温使用 0–100 的冷暖百分比。
- 翻页动画默认关闭。开启后只调用 KPW6 显示驱动的一次性整屏滑动动画，不再创建软件动画帧、定时器或双图片缓冲；分屏同一张图片的左右页切换也会使用对应方向的原生动画，适宽上下移动不启动动画。开启“每页完全刷新”后，每次切换到新的物理图片使用黑白完整刷新以清除残影，并自动跳过翻页动画；同一张宽图内部切换不会重复黑闪。
- 可选“自动裁切最外圈浅色边”，默认关闭；开启后只在已解码的图片缓冲区上检测。默认识别强度为 24%、每侧最多裁切 15%；识别强度可在 0–100% 调整，数值越大，越容易把偏灰的浅色边识别为白边；每侧最大裁切比例可在 0–30% 调整。算法也识别明亮、低到中等色差的浅黄色旧纸张，但遇到连续墨线、深色边或高饱和装饰色会停止裁切。检测异常或缺少像素接口时保留原图，不影响继续阅读。
- 成功下载、解码并显示页面后才写入历史。阅读历史按最近时间排序，记录漫画、章节、页码、百分比和时间；从历史打开会按图片路径优先恢复进度。
- 历史项的“删除”只删除本地历史记录，不会删除远程文件、缓存以外的文件或连接设置。
- 浏览过的目录、章节和页面索引会保存在本机。WebDAV 离线时可使用已保存的目录，且只有已缓存图片页能够显示；刷新目录、首次识别漫画和未缓存图片仍需要联网。本地目录不需要网络，文件变化后点“刷新”读取最新清单。
- 连接重新保存时，本地书架上下文按连接身份隔离；不同服务器、账号或根目录不会复用旧位置。书架重关联目录只更新本地分类架记录，**不会迁移阅读历史或进度**。

## 封面与漫画分类架

从“WebDAV 漫画 → 漫画分类架”进入本地分类架。它包含 **全部 / 未分类 / 自定义分类**；可以新建、重命名和删除自定义分类，并可为一本漫画选择多个分类（多分类）。

“添加漫画”或“重新关联目录”会重新识别目录。分类架封面优先使用已保存的封面索引；没有索引时，算法会选取漫画目录中按自然顺序排列的第一张支持图片；若是章节结构，则逐章查找并采用第一个有支持图片的章节中的第一张图片。封面取得失败、离线或远程路径不可用时，列表保留漫画名称和占位状态，不把失败结果当作封面缓存；在“管理 → 刷新封面”后可重新尝试。

“从当前分类移除”只移除该分类关系；“从漫画书架移除”只删除本地书架记录。二者都不会删除远程文件。删除分类也只删除本地分类名称，漫画记录会保留。

## 流式下载与缓存

- 当前页优先下载。默认第 1～10 页预加载后续 5 页，第 11 页起预加载后续 2 页；“网络加载”设置可分别调整前段边界（1～100）、前段预加载页数（0～10）和后段预加载页数（0～10），也可关闭 HTTP Range 分段加载。关闭后仍使用完整 GET，不改变图片阅读器行为；文档是否能真正按页流式阅读取决于 KOReader 宿主是否提供 `showReaderStream`。
- HTTP Range 只用于图片页和文档的可恢复暂存。图片页按分段响应组装后才交给 KOReader 解码；服务器不支持 Range 时自动回退完整 GET。回退会删除不完整的 `.part` 文件，避免下一次误用损坏片段。
- Kindle 本地目录使用直读路径：校验通过后直接交给 KOReader 解码，不经过 WebDAV、插件缓存或临时复制；前后页仍按预加载策略检查。显式执行“缓存到 Kindle”时才会复制文件。
- 图片缓存默认上限为 200 MB，可在“阅读设置”调整为 16–4096 MB。
- 达到上限时自动淘汰最久未使用的图片，当前页与相邻页受保护；已知大于上限的单页不会开始下载。
- 历史和漫画分类架使用独立的 `cover` 缓存类型，命中后优先从本机快速渲染；“连接设置 → 管理封面缓存”可查看封面索引占用和数量。
- “缓存管理 → 清空图片缓存”和“管理封面缓存 → 清理封面缓存索引”只删除本地缓存索引，不删除 NAS、Kindle 或本机缓存图片文件，也不删除阅读进度、历史、分类架或连接设置。

遇到连续“图片无法解码”时，先进入“缓存管理 → 清空图片缓存”，再回到章节重新下载。这是损坏缓存的推荐恢复方式，不需要卸载插件，也不会清除阅读历史、分类架或 WebDAV 连接。若只有单页失败，可直接在错误页点“重试”或跳到下一页。

## 设备诊断与安全

在 **WebDAV 漫画 → 关于 → 图片格式兼容性检测** 运行设备诊断。它会用发布包内的确定性样本逐项显示 JPG、JPEG、PNG、WebP、GIF 首帧、TIF/TIFF 和 SVG 是否可以在当前 KOReader/设备上解码；诊断结果不是 KPW6 真机验收的替代品。

密码只保存在 Kindle 本机的 KOReader 设置目录中；插件不会在历史、错误提示或自身日志中输出密码或完整 Authorization 凭据。HTTP 上的 Basic 凭据没有传输加密，除完全可信且隔离的局域网外请使用经证书校验的 HTTPS。提交日志前请自行遮盖服务器地址、用户名和远程目录。

## 当前限制

- WebDAV 和 Kindle 本地来源均为只读；本地来源只允许访问配置根目录以内的安全路径。
- 不支持压缩漫画包、BMP、AVIF、HEIC 或 GIF/其他动画播放。
- 0.3.76 去灰及亮度/对比度只走受支持的快速内存通道，不提供通用逐像素回退、色阶、曲线或大图锐化；不支持快速处理的图片仍可按原图阅读。
- 0.3.17 不包含联网授权、固定密钥、设备绑定或七天试用；商业授权功能留待后续独立版本设计。
- KPW6 的六种格式实际渲染、内存峰值、墨水屏刷新与手势体验仍需真机验收。
