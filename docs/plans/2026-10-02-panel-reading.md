# 智能分格阅读重构规划

> 使用 executing-plans 在当前分格分支逐阶段实现；每阶段先复现失败再修复，最终新上下文独立审查。

**目标：** 改进检测和复杂排序，降低对白裁切，增加独立分格旋转与自定义翻格方向。不是任意漫画的自动完美识别承诺。

**设计：** 保留PanelSource/PanelSession的原图所有权、异步token和逐格渲染。检测基于已显示缓冲建立背景相对的有界墨迹图；参考Panels+固定MIT算法，原始框用于排序、保护框只用于显示，未覆盖内容保守加入取景或回退整页。分格旋转只作用于返回的显示缓冲，不改变设备或原图。三视图共用相同窗口计算和Session，避免三个独立阅读器。

**方案：** 只加边距改动小但无法解决漏检；完整移植阅读器有文档/手势/许可证耦合；推荐有限算法适配及取景重构。Meguru仅研究行为，不复制AGPL源码；Panels+复制的MIT算法保留完整来源与许可。

**技术与约束：** Lua5.1/KOReader既有Blitbuffer、MuPDF；不新增原生库/网络服务/扫描数据库。检测采样和组件数设硬上限；保留加载、章节边界、气泡与双指功能。默认带上下文取景并保护对白；经典刷新优先于尚未设备验证的连续动画。

**参考：** Meguru 217a52371c02db19cf2a19ceb0b5ccd32b358c4e；PanelsPlus 14c53e9daec5a34e627dddb3bd52483ddb787bad。读取源码证实两个项目都不能保证任意对白完整：不能照搬等同精准。排序不得使用显示扩展框；字符串方向必须明确比较manga，避免comic也被Lua当成true。

## 阶段1：检测、保护框与排序

修改panel_detector.lua，新增独立panel_analysis.lua及MIT检测/排序窄适配；package_contract.py与NOTICE登记来源。接口detect(raster,{direction,...})仍返回带稳定id的归一化格列表，frame/保护取景分离，原注入backend作为受控后端保留。PanelSource.detection_raster传借用buffer与crop；不额外完整解码做检测。

- [ ] 新增复杂跨行/嵌套/等坐标稳定排序、白/黑背景、斜格、突出对白、错误页回退与采样上限规格，旧实现先失败。
- [ ] 实现有界墨迹分析、检测可信度、内容保护与排序；原格框不随保护扩大。
- [ ] 阶段检测与旧相关规格通过，记录真实样本局限；每次只验证一个根因。

## 阶段2：取景与独立旋转

新增panel_view.lua纯几何；PanelSource.render共用cut/context/free窗口，保留像素预算。Session增加configure/zoom/pan，配置失败保留当前图和索引；prefetch只缓存同配置。0/90/180/270度旋转保持源图不变，旋转前后严格释放恰好一次。

- [ ] 新增保护对白完整适屏、上下文画面、全页自由视图、旋转像素方向、缩放/拖动变换、极端比例、预算及故障注入规格，观察失败。
- [ ] 实现单一相机窗口与安全旋转，四角、黑背景、返回与配置失败验证通过。

## 阶段3：阅读器操作与设置

分格中间点按打开控制，提供视图/倍率/旋转/顺序/横纵翻格/退出；自由查看只缩放与移动，不隐式翻页。点按设置用于当前书，长按设为新书默认；使用既有Settings存储有界书级panel偏好，不写账号或服务器地址。全局编辑仍设置默认。阅读器重载合并当前书偏好。帮助说明同源更新。

- [ ] 验证点按/滑动/硬件按键、原图恢复、书级隔离和长按默认、存储失败、并发渲染/晚到回调与气泡/双指互斥。
- [ ] 实现设置与手势；不在切换阅读设置时重新下载页面。
