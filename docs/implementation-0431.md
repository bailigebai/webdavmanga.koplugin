## 审查及修复

一次独立新上下文审查，范围 `e68c423..721f906`；未发现 Critical，发现五项 Important，均采纳并在同一修复阶段处理。本轮没有再次委派审查。

1. 整页回退时切换模式：第一格渲染、保存或发布失败，原来仍保存新模式且清掉续读状态。改为首次发布事务，恢复旧设置、整页和下一页检测。覆盖同步、异步、保存拒绝、发布拒绝、构造失败、无格、晚到回调及保存中关闭。
2. 原生系统返回或点窗外：原来绕过注册表和父页恢复。现在和明确返回按钮共用所有权检查及返回逻辑，退出清除所有权后不恢复旧窗口。
3. 共用视图与高级设置：原来用当前启用模式推断父页。现在保留实际进入来源，Web 页面从 Web 返回，智能页面从智能返回。
4. 全局子窗口构造异常：原来父页已经关闭。转换失败时恢复原父设置页，并保留退出代次保护。
5. 渲染中关闭分格：原来直接保存后释放来源。检测、渲染、配置或发布忙期统一拒绝设置修改，结束后可重试，避免在原生渲染栈中关闭来源。

已保留每条复现失败与通过证据。验证摘要见 `verification.md`，源码绑定 ARM 报告见 `panel-analysis-0431.json` 与 `stream-formats-0431.json`。

## 实施裁决、依据和代价

1. 提前扩展共用数字验证以支持动态最小宽高的小数，已有整数规则不变。若判断有误，需要为新的数值字段另设规则。
2. 两份固定上游算法仅作为测试夹具，严格排除在安装包外。若上游接口变化，需要更新独立对照夹具和提取测试。
3. Web 共用现有视图和导航，只独立保存四项识别参数。若未来需要独立相机偏好，再单独设计数据模型。
4. 白话保护使用 `min(有效阈值, 手动阈值, 40)` 的同次采样，避免抬高检测阈值遗漏浅色越框文字。若噪声过多，可关闭自动匹配并使用手动阈值。
5. 原生自动统计只采请求裁切范围内的像素中心，保留原裁切取整。若取样过少，自动策略回退手动基准。
6. 不添加额外弱线重试：已有有界自动匹配，缺少真实标注准确率证据。代价是部分复杂页仍需手调或整页阅读。
7. 修复原有纯 Lua CRC 性能，使用固定256项半字节 XOR 表；原生 bit 路径和严格3秒完整性门槛不变。代价是多一张固定小表，已通过 CRC 和七格式原文件验证。
8. 活跃分格调参在同一 Session 中构造候选布局后原子替换，避免先关闭旧来源而丢失可回退画面。代价是候选期间最多同时保留当前格和候选格。
9. ARM 真页面格数不代表准确率，因此不以格数增加为弱线重试或“更精准”承诺依据，自动识别默认关闭。代价是视觉精准度仍需实机验收。
10. 原生正常关闭复用明确返回入口，退出先失效所有权。若某种新窗口有特殊原生关闭约定，需增加对应适配。
11. 共用菜单记录实际来源，回到阅读或根页时清除。若新增其他来源，应明确传递其父页。
12. 整页回退切模式以首次成功发布为提交边界；迟到结果及关闭中保存不能复活阅读器。代价是异步识别期间新设置尚未生效。
13. 忙期设置直接拒绝，不添加延迟队列。代价是偶发忙碌时需要再点一次，避免新增资源释放和过期任务分支。
14. 真实Kindle触控、墨水屏和体感性能保留为实机验收边界。代价是设备专属问题可能需要下一次修复。
15. 真实漫画精准度保留为需标注验证的边界，识别格数不构成准确率证据。代价是复杂页面仍可能需要手调或整页阅读。
16. 未接入的仅path/bytes原生自动入口不扩展，正文实际使用buffer。代价是未来接入者需补接口和原生测试。
17. 打包CLI保留stream-report接口，分格ARM报告另行执行并核对同一源码。代价是后续发布者需记得执行两道门禁；本轮均已通过。
