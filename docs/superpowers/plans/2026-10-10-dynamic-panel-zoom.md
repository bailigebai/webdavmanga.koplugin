# 动态面板变焦临时实施计划

> **For agentic workers:** 使用 superpowers:executing-plans，在当前隔离工作区逐阶段实现并验证。

**Goal:** 添加独立的“动态面板变焦”，与智能分格互斥；原生实时检测、居中聚焦、下一格预渲染、双向顺序与长按周边原图自由缩放。

**Architecture:** 新增动态模式策略模块，调用 KOReader 已带的 Leptonica。共用经过验证的 PanelSource / PanelSession / ReaderShell 资源生命周期，不挂钩 KOReader 全局阅读器。动态模式有独立配置，普通聚焦固定独立格、经典切换。

**Tech Stack:** Lua 5.1 / LuaJIT、KOReader Blitbuffer、Leptonica、原生 ImageViewer；不增加依赖。

**Spec:** 本文用户需求与方案部分。

## 用户需求与方案

参考 JorgeTheFox/koreader-dynamic-panelzoom，固定参考提交 9ff32bf0ac91e4f7f471c1eed8c2025ef8fb04c4（MIT）。

| 方案 | 好处 | 代价 |
| --- | --- | --- |
| 搬入上游整套阅读器与全局挂钩 | 接近原项目 | 重复书页、浮层与内存生命周期，影响 KOReader |
| 把动态检测加入智能分格 | 改动少 | 用户无法使用两个独立开关与配置 |
| 独立模式，共用显示/会话资源 | 满足独立与互斥，减少资源重复 | 需补充模式路由与原生检测适配 |

采用第三种。两个开关都能关闭，开启其中一个会关闭另一个；保存、读回、当前书覆盖和重新载入均保证互斥。启用后整页长按进入，未检测到可靠面板则仅该页显示整页，下一页继续检测。中央点按显示动态控制，边缘导航按阅读顺序。气泡点击优先级保留。

动态独立项：开关、跟随/左到右/右到左顺序、聚焦边距 0/2/5/10%、长按扩展 2/5/10/15/20%、初始缩放 1/1.2/1.5/2 倍。周边扩展读取实际原图内容，不用空白边距代替对白。设置点按当前书，长按新书默认。

## 全局约束

- 原生分析只使用有界的当前页缓冲采样，不重复下载全书或解码不受限的大原图；最长采样边 960，候选面板最多 64。
- 预渲染只保留下一格一张缓冲；关闭、换页、切模式后迟到任务无效。
- 原生不可用/失败时保留原页并说明原因；不能冒用智能分格作为动态原生检测成功。
- 本次只添加该模式，保留七格式流式读取和退出背景修复。
- 交付增加 ZIP 与 SHA256、本地同份 ZIP、公共 GitHub 发布；设备连接则备份后安装逐文件校验。
