# 临时设计：漫画设置层级与三种分格模式

状态：设计草案，待用户审阅；产品代码尚未修改。

## 需求与事实来源

本次修改已有 WebDAV 漫画插件，不创建另一套阅读器。基线为 v0.4.30，提交 `e68c4236c45a19c84ea6b3f2a7a8faa4bfefcfcf`，开发工作区为 `E:\jiankong\webdav-manga-handoff\worktrees\panel-reading`。

最新补充明确要求“删除截图按钮和功能”，覆盖原需求中不明确的截图表述。删除插件的“当前视图截图”入口、实现与说明，不改变 KOReader 自身的截图能力。

本次包含以下完整需求：

1. 进入内层设置时隐藏父设置；每个内层页面均提供“返回上一级”，准确返回直接父页面。
2. 删除“分格视图、旋转与方向”中的“当前视图截图”按钮及其功能。
3. 动态面板阅读不显示“动态面板…”常驻状态字样，切换进入时清理上一模式的状态。
4. 动态面板的识别参数支持输入准确数值，原识别强度保留为默认；增加按页面明暗自动匹配强度的高级设置。
5. 设备旋转独立放到阅读设置首页，提供 0°、90°、180°、270°。设备旋转与只旋转分格内容分别管理。
6. “更多分格设置”直接置于“智能分格阅读”下，不再放在“分格视图、旋转与方向”内。
7. “更多分格设置 → 裁切、对白保护与识别”增加“高级分格识别”，可按页面明暗自动匹配强度。
8. 增加独立的“web分格”，从最新 MangaWeb 提取真实识别实现，与智能分格、动态面板两两互斥。

发现的现有行为：`ReaderShell:show_number_input` 打开独立输入窗口后，`current_model` 仍为父级 `controls`；已用真实 Shell 方法和注入的原生窗口边界复现。全局设置与阅读器控制页由两套 UI 管理，部分编辑器不能统一隐藏下层控制画面。现有智能分格阈值为 40；动态面板原生阈值固定为 50，最小宽高为页面宽高的 1/8。

## 三种方案与选择

| 方案 | 内容 | 取舍 |
| --- | --- | --- |
| A，推荐 | 三种独立识别策略，共用现有来源、分格会话、渲染与退出流程；统一模式互斥和设置导航 | 满足独立能力，复用已有缓冲所有权与缓存，改动边界清楚 |
| B | 将 Web 参数并入智能分格，合并为一个识别器 | 改动较少，但不满足三个可独立切换的模式 |
| C | 复制整个 MangaWeb 阅读器与设置、存储 | 重复管理缓存、手势与退出，维护成本及冲突风险更高 |

采用 A 的设计草案。此文档不授权新增网站连接、下载源或 MangaWeb 授权逻辑。

## 设置页面及返回关系

阅读设置首页保留现有功能，增加“设备旋转”和“web分格”。

```text
阅读设置
├─ 设备旋转 → 0° / 90° / 180° / 270°
├─ 智能分格阅读
│  ├─ 分格视图、旋转与方向
│  └─ 更多分格设置
│     ├─ 分格翻页动画
│     ├─ 触发手势与导航
│     └─ 裁切、对白保护与识别
│        └─ 高级分格识别
├─ 动态面板变焦
│  ├─ 数值识别参数
│  └─ 高级动态面板识别
└─ web分格
   ├─ 视图、顺序与方向
   └─ 识别参数
```

每个分支及其数值编辑页都有“返回上一级”。保存返回直接父页；返回或取消不修改草稿前的设置。设置最外层关闭后回到原阅读页或打开设置前的书架。

设置导航按逻辑父页面管理，只显示当前页。阅读器自身的控制页面优先复用同一个不透明 Shell；外部原生编辑器打开前隐藏控制按钮，保留漫画插件的不透明底图。不得用关闭整个插件背景的方式隐藏父菜单。

外部设置窗口切换保留现有 `dialog_epoch` 和注册表的关闭保护，退出后迟到回调不得重新打开页面。数值输入、选择页、帮助及现有增强编辑页纳入检查范围，而不只检查新增分格菜单。失败时恢复原父页面或原阅读画面，不能留下空白或被锁住的背景。

## 三种模式的职责与互斥

统一模式策略负责：选择当前模式、启用时关闭另外两种模式、合并全局与本漫画设置、判断是否继续跨页识别。识别器仅负责返回分格及保护范围，不管理网络或窗口。

继续使用三个明确的启用字段：`panel_zoom_enabled`、`dynamic_panel_zoom_enabled`、`web_panel_zoom_enabled`。用户明确开启哪个字段，哪个模式生效，另外两个关闭。关闭当前模式时不自动开启另一模式。

全局设置、按漫画保存、长按设为默认、恢复默认和加载配置均使用同一互斥规则。本漫画显式选择必须覆盖另外两个全局默认。非法或冲突配置按确定规则规范化，不能同时创建两个分格会话。

切换模式先安全解除旧画面借用，再关闭旧会话、取消预渲染并使用当前本地页建立新会话。保存、显示或建立会话失败时保留或恢复原设置与画面。单页检测失败显示整页；模式保持开启，下一页继续识别。物理页位置不改变。

保留现有气泡点击优先级、双指象限触发、顶部及底部 KOReader 菜单区域、整体插件背景与确认退出行为。三种模式不另建手势监听器，继续通过现有阅读器路由分派操作。

## 动态面板数值参数

新增 `dynamic_panel_detection_threshold`，整数 1～254，默认 50。保持原生 Leptonica 默认连通性 8，最多 64 格，不开放无界候选数量。

新增 `dynamic_panel_min_side_percent`，允许有限数值 2～50，默认 12.5；表示候选宽和高分别至少占页面宽高的比例。默认等价于现有 1/8 策略。降低比例仍需通过完整候选检查，不保证格数必然增加，也不能仅因数量增加就宣称准确度提高。

数值输入明确单位与范围，拒绝空值、非数、无穷、NaN、越界，以及要求整数的阈值中的小数。失败不改旧值。默认关闭自动识别时，原生阈值、过滤、分格顺序和显示必须与当前默认一致。

## 高级自动识别

智能分格与动态面板分别保存自动识别开关，默认均关闭。位于各自指定的高级设置页面，不能混淆为现有“自动黑白背景”显示选项。

开启后统计本页有界灰度采样的背景明暗和相对灰度差分布，使用直方图分离背景与前景，并把本页有效阈值限制在手动基准的 50%～150% 且 1～254 内。智能分格沿用最长边 480 的采样；动态原生后端沿用最长边 960 的限制，避免另解码一份全尺寸原图。确定的黑、白、灰色背景均需覆盖，不能只凭整页均值反转页面。

自动阈值仅用于当前检测，不写回手动数值、不修改原图、不重新下载，不能重新开启已关闭的亮度、对比度或去灰处理。空白、均匀色块或无法稳定分离前景的页面安全回到基准检测或整页。

对于其他自适应方法，实施时只评估一次受限的“弱线补充识别”：主识别无法形成可靠多格时，以较低阈值再试一次。只有真实样本证明结果通过边框、排序和对白完整性校验，才增加独立默认关闭的开关；若不能证明，交付说明明确不加入该选项。不得无限尝试多个阈值，或用“格数最多”选择结果。此项为用户提出的条件性能力，不是缩减必需的自动明暗匹配功能。

每次调整识别参数使用当前本地页重新识别，保持物理页，重新从首格开始。老预渲染与回调取消；旧缓冲只释放一次，仍被显示器借用的缓冲不得提前释放。保存失败回滚参数和画面；检测不确定回到整页并保持后续页面检测。

## 旋转与状态显示

设备旋转使用 KOReader 公共 `SetRotationMode` 事件并明确选择四个角度，而不是只能不断加 90°。旋转后重新查询屏幕尺寸、重建触摸区域、重新适配当前页，保持物理页和模式。不在旋转时重复下载。

分格内容旋转继续是独立的视图参数。只调整内容旋转不旋转设备菜单。设备旋转失败必须显示真实错误并保留可继续操作的页面。

动态面板不显示常驻“动态面板 n / m”。进入时采用不含模式名称的短暂识别提示，成功后清除提示；错误或保存失败仍可以显示。不得为隐藏文字而把所有错误提示一起屏蔽，也不得恢复整页闪刷来清理一个小状态区域。

## 分阶段验收与交付门禁

1. 设置导航：全局及阅读器两种入口逐层进入、逐层返回、保存、取消、关闭、布局失败及迟到回调；窗口栈和实际画面证明只显示当前设置且保持整体插件背景。截图入口、实现、说明均删除。
2. 基础控制：外层旋转四个角度；更多分格设置位置正确；动态成功画面无模式状态文字。原图关闭处理逻辑、确认退出插件、菜单触摸区域、气泡优先级和象限手势不回归。
3. 模式与参数：三种模式按全局/本漫画/长按默认两两互斥；每个新数值真实进入检测器；默认结果一致；无效配置与保存失败保留旧状态。
4. 识别行为：黑底、白底、灰底、浅线、溢出对白、复杂排序、空白页、未识别页之后继续识别。自动开关确实改变检测参数，关闭后恢复手动基准；Web 默认与固定来源算法框、保护范围和顺序一致。
5. 生命周期：连续调参、切模式、跨页、旋转、退出、布局拒绝、取消与迟到回调；不重复释放、不读已释放页、不重新取当前原图、不发布旧布局。
6. 发布前必须重新通过完整 Lua 规格、产品语法、发布门禁，并用 `E:\测试` 原始七份 ZIP/RAR/RAR/7Z/EPUB/PDF/AZW3 文件验证严格 Range 流式打开和实际像素解码，不能以完整下载回退冒充流式成功。对检测器改动补充真实 ARM LuaJIT、BlitBuffer 和 Leptonica 证据。
7. 包内只包含本插件与必要说明，校验安装 ZIP、散列和版本；开发完成按此前授权更新公开 GitHub 并同步本地安装压缩包。未连接设备时不能声称已安装或已实机验收。

准确度验收区分：自动样本框和对白完整性检查、真实 Kindle 画面，以及用户认为更好读的实际体验。自动测试不能替代用户对复杂分格和旋转阅读的实机评价。
