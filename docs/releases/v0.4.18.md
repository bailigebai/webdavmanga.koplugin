# WebDAV Manga v0.4.18 · 书架与设置修复套装

设备测试版。推荐下载 `webdavmanga-repair-0.4.18-graydither-0.3.1.zip`，两个插件文件夹都要更新。

设备日志已经确认：漫画书架打开报 E0003，以及定期缓存清理导致 KOReader 退出，都进入 `cache.lua` 的文件大小读取。未创建的临时文件使文件系统返回 `nil, error`，错误字符串误成 `tonumber` 的进制参数。

修复在四个消费处明确只取大小的第一个返回值：临时文件、目录辅助文件、文档大小校验和发布。保留原来缺文件计为 0、辅助文件目录大小退回、文档大小未知与发布失败规则。无新增依赖和设置。

含 0.4.17 已有设置预览与延迟切换稳定性修复。套装同时包含 GrayDither 0.3.1，修复自动刷新次数与保持时长数字框被设置菜单遮挡，并保护窗口构造、显示、关闭、保存异常和退出后的旧回调。图片算法、默认参数、来源设置隔离和缓存安全规则沿用现有行为。验证命令和结果见 `docs/verification.md`。

安装：完全退出 KOReader，备份现有两个插件；将完整套装中的 `webdavmanga.koplugin` 和 `graydither.koplugin` 放入 `koreader/plugins/`，覆盖程序文件，保留缓存与 KOReader 设置目录；重启确认 WebDAV Manga 0.4.18、GrayDither 0.3.1 均已启用。单独 WebDAV 包不能替代 GrayDither 的数字框修复。

打开“WebDAV 漫画 → 漫画书架”，切换列表/封面，进入和返回目录，刷新目录，再打开“漫画书架封面缓存”执行按规则清理。重复操作，并在超过原10分钟检查间隔后继续操作，预期无 E0003、书架可显示、缓存占用正常、KOReader 不退出。记录实际发生异常的时间用于核对日志。

阅读设置验收：进入正文设置 → 灰度抖动与墨水屏刷新 → 墨水屏刷新 → 自动间隔，将5改4，确认后重新进入应显示4，可恢复默认5。反复调整开关、时长、预览和返回阅读，检查窗口可操作、设置保留和正文正常。

GrayDither 独立发布页：https://github.com/bailigebai/graydither.koplugin/releases/tag/v0.3.1 。
