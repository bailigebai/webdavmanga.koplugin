# WebDAV 漫画 v0.4.17 · 设置稳定性修复

## 本次修复

- 去灰、亮度/对比度和 KOReader 图像处理预览重复打开时，先关闭旧窗口再释放图片，避免使用已释放的图片内存。
- 每个预览单独管理自己的图片。旧窗口迟到的关闭事件不会影响新预览；正常返回、原生关闭和退出设置回收对应资源。
- 预览显示失败会回收图片；关闭失败时保留当前可见图片并停止替换。
- 设置页面的延迟切换复用错误保护。关闭设置或打开新页面后，取消旧回调，防止异常退出和旧设置页重新出现。

只修改现有设置流程，不增加设置项、依赖或漫画功能。封面书架、授权、连接与阅读设置保留，并合并已发布 v0.4.16 的 GrayDither 可选接入；其两个开关仍默认关闭，需 GrayDither 0.3.0 或以上才能使用。软件16级灰度不等同硬件256级，真实全刷与残影仍需设备验收。

## 下载与安装

下载本发布的 `webdavmanga.koplugin-v0.4.17-20261008-settings-stability.zip`，解压得到 `webdavmanga.koplugin` 文件夹。

1. 完全退出 KOReader，备份原插件。
2. 将整个文件夹覆盖到设备 `koreader/plugins/`，检查最终存在 `koreader/plugins/webdavmanga.koplugin/main.lua`。
3. 保留 KOReader 用户数据和 `settings/`，尤其是 `webdavmanga.lua` 与 `webdavmanga-license.lua`。
4. 完全重启 KOReader，在“关于”确认版本 `0.4.17`。qiqi 应用商店可刷新后选择本版 ZIP 附件安装。

安装包包含124个运行文件，874205字节。两次构建字节一致，逐文件与源码清单一致，本地交付目录保留相同副本。SHA-256：`0094a85c79a70be98ca77d792176edb6f2ba3173399e82e20c8ae90419d46714`，附独立 `.sha256` 文件。
