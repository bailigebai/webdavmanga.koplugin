# WebDAV Manga v0.4.19 · 流式目录缓存修复

修复旧 EPUB 目录缓存重复使用封面路径造成的 `stream_failed`：检测整个目录的重复路径，只重建当前书的无效索引，保留合法重复封面的阅读页序。

原文件验收同时发现 AZW3 最后一个 `FDST` 索引记录被当成漫画页。本版按有效 KF8 多流头信息排除该索引；真实末页保留，单流与旧 MOBI 的同位置字段不作为 FDST 边界。字段依据 [KindleUnpack 的 MOBI/KF8 头解析](https://github.com/kevinhendricks/KindleUnpack/blob/master/lib/mobi_header.py)。

新增强制交付门槛：七份原文件（两份 RAR、EPUB、PDF、ZIP、7Z、AZW3）在 ARM 原生环境中完成首次打开、重复打开、前20页与末页缓存加载及完整图片解码；另测旧 EPUB 缓存恢复。检查失败或报告不对应当前运行代码就不能打包。可复跑命令与真实测试边界见[流式检查说明](../stream-formats.md)。

安装：完全退出 KOReader，备份原插件；解压 `webdavmanga.koplugin-v0.4.19-20261009-stream-cache-fix.zip`，把完整 `webdavmanga.koplugin` 放入 `koreader/plugins/` 覆盖程序文件，保留设置和缓存，重启后在关于确认 `0.4.19`。已有 GrayDither 0.3.1 无需重装。

验收：在测试目录依次打开七份文件，不选择完整下载；检查首页、连续翻页、末页、退出后再次打开。旧 EPUB 缓存应自动恢复，无需清空全部缓存。

真实 Kindle 安装、触摸、墨水屏与 live WebDAV 尚待连接设备验收。固实 7Z 的前缀解码累计流量仍可能较大；本版不保证所有文档变种或所有页面都能流式解析。
