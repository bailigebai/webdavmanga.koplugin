# v0.4.26：独立网格象限缩放

开启“阅读设置 → 网格象限缩放”后，双指轻触当前画面的左上、右上、左下或右下象限，按两指中心点选择区域并完整等比放大适屏。默认关闭，独立保存；单指点按、双击和双指按住不进入此功能，抬起手指保持放大。再次双指轻触或单指点按恢复原画面。

本次改动：

- 可单独开关 2×2 十字辅助线；放大时隐藏，恢复后显示。
- “缩放期间右到左”只改变放大时左右滑动的翻页方向，恢复、换页或退出后使用原方向，不修改 KOReader 文档或全局方向。
- 拆页放大当前左/右半页，适宽放大当前滚动窗口，裁边与奇数尺寸保留最后一列/行；借用已有图片，不重新下载、解码或写进度。
- 点按选项应用当前漫画，长按同一项同时保存新漫画默认；全局阅读设置增加网格默认值分组。设置或显示失败保留原配置和画面。
- 开启网格后暂停旧双指按住临时象限，整页双指入口优先用于网格，分格仍可单指长按进入；已进入的分格和长条不叠加网格。关闭网格恢复分格入口与旧临时按住功能。
- 对白点击/浮层关闭、上下各1/12原生菜单、右上双击退出保留优先级。宽图拆分和手动设备旋转沿用现有功能；自动设备旋转本次没有加入。

参考 [Maximum](https://github.com/Shac0x/maximum.koplugin) 提交 `0f4d1fc656c4eb1f2fe1262ceceb88e7ffb7d3b8` 的交互，按本插件已有视口和窗口生命周期独立实现，没有复制它的全局缩放或旋转钩子。

安装：下载本页 `webdavmanga.koplugin-v0.4.26-20261010-grid-quadrant-zoom.zip` 和同名 `.sha256`，完全退出 KOReader，备份原插件并覆盖 `koreader/plugins/webdavmanga.koplugin`，保留用户 settings 和授权文件，重启确认版本 **0.4.26**。

验收：

1. 开启网格，在四个象限分别双指轻触，选中的区域应等比放大；长按双指或单指点按不得进入。再次双指轻触/单指点按恢复。
2. 打开辅助线和 RTL，检查线条、左右滑动及退出缩放后方向恢复。拆页和适宽滚动到中间时，检查没有跳到隐藏区域。
3. 点按设置只改当前漫画；长按设置后新漫画使用默认。开启网格与智能分格，双指进网格，长按进分格；对白命中和上下菜单仍优先。
4. 逐个打开测试目录的两份 RAR、EPUB、PDF、ZIP、7Z、AZW3，检查首屏、翻页、关闭；列表/封面书架及确认退出返回 KOReader。

真实 Kindle 触摸识别、墨水屏刷新和服务器连接仍需实机验收。当前版本的自动检查证据见仓库 `docs/verification.md` 与 `docs/stream-formats-0426.json`；本机同步提供与发布相同的 ZIP。
