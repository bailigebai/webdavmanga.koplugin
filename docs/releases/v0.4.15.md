# WebDAV 漫画 v0.4.15 · 封面书架

## 本次更新

- 漫画书架支持列表／封面切换，按钮位于左上角“切换连接”旁；记住显示方式与浏览位置。点封面进入文件夹，长按选择阅读或缓存，底部“操作”保留历史、刷新等入口。
- 优先读取当前文件夹数字自然排序首图；无直属图片时只查下一层子目录，空目录继续查同层下一项。方图、横图和长图完整等比缩小，仅加载当前屏幕。
- 新增独立“漫画书架封面缓存”，默认最大200MB、超过150MB清理到100MB、每10分钟检查。可修改容量与间隔，手动按规则清理或清空生成缓存；使用中的封面、目录会保留。
- 源图下载、目录排序临时文件及索引共用容量预算；未知或错误文件大小也在写入前限制。生成缩略图后移除缓存源图，本地大原图只直读。
- 刷新书架同时使对应阅读目录索引失效；清理结果区分使用中大小与实际剩余占用。

## 下载与安装

下载本发布中的 `webdavmanga.koplugin-v0.4.15-20261007-bookshelf-covers.zip`，解压得到 `webdavmanga.koplugin` 文件夹。

1. 完全退出 KOReader，备份原插件。
2. 将整个文件夹放入设备 `koreader/plugins/`，覆盖已有插件代码；最终应有 `koreader/plugins/webdavmanga.koplugin/main.lua`。
3. 保留 KOReader 用户数据和 `settings/`，尤其是 `webdavmanga.lua` 与 `webdavmanga-license.lua`。授权、账号和阅读记录不包含在安装包中。
4. 完全重启 KOReader，主菜单进入“WebDAV 漫画 → 漫画书架”，在“关于”页确认 `0.4.15`。

也可在 qiqi 应用商店刷新项目列表，打开 `bailigebai/webdavmanga.koplugin`，选择 `v0.4.15` 的 ZIP 附件进行安装。

安装包 SHA-256：`c396c6c1465fe3910756149a37ef52bfd63946e0bc5184941a75f9e3bc65aeb6`。发布同时附有 `.sha256` 校验文件，仓库 `releases/` 和本地交付目录保留相同字节的安装包。

## 验证与验收

开发完成后的完整回归通过192组测试、107个 Lua 文件语法检查；安装包123个文件，两次构建字节一致，逐文件内容与源清单一致。独立审查发现的5项重要问题及1项清理提示问题已修复；证据见 [验证记录](https://github.com/bailigebai/webdavmanga.koplugin/blob/main/docs/verification.md)。

安装后检查：切换列表／封面并重新进入，确认选择与位置保留；用001、2、10图片检查首图顺序；检查首个子目录为空时继续下一项，且不进入孙目录。测试点按进入、长按阅读／缓存、断网重开已访问目录，以及“缓存管理 → 漫画书架封面缓存”的设置与清理。

## 当前限制

本次封面目录用于 WebDAV 和本地书架，OPDS 沿用原导航。纯归档／文档目录保留可进入的占位卡片，封面缓存不代表整本漫画离线。复杂相连、斜格、无框或嵌套漫画仍可能无法准确自动分格。

本次未检测到 Kindle，尚未安装或完成触摸、PNG显示、首屏耗时及墨水屏刷新验收。本机检查不能替代真机结果。
