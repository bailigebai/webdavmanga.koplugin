# WebDAV 漫画 v0.4.16 · 灰度抖动与墨水屏刷新

本版为设备测试版。电脑回归与安装包检查已通过，Kindle 触控、全刷波形、残影及性能仍需真机验收。

## 本次变化

安装并启用 GrayDither 0.3.0 或以上后，在漫画正文点画面中间，选择“灰度抖动与墨水屏刷新”。灰度和自动全刷两个开关独立保存、默认关闭，只用于本来源内置阅读器。缺失、禁用或服务失败时继续原方式阅读，保存失败保持原设置。

灰度使用 16 级软件 Floyd–Steinberg，在去灰、亮度/对比度及最终缩放之后处理显示正文，不修改原图片和解码缓存；不等同硬件 256 级灰度。整页、拆页、适宽滚动、象限、长条连续和分格都可使用；缩略图、气泡、设置与文字提示沿用原显示。

自动全刷按成功显示的新画面计数，首次、同屏重绘、预加载和设置不计。间隔1～50次、默认5次；可选原生全刷或黑白辅助，黑白各保持0.1～1秒、默认0.3秒。立即全刷先返回正文。共享服务有效时临时暂停原每页全刷与页动画，保留原偏好；关闭或服务异常时恢复原刷新策略。

加载保留翻页进度并取消待执行阶段，设置/休眠重建首屏基准，旋转重置，阅读器退出或宿主直接关闭窗口都会取消刷新任务并清理浮层。

## 安装与验收

从 [v0.4.16 Releases](https://github.com/bailigebai/webdavmanga.koplugin/releases/tag/v0.4.16) 下载 `webdavmanga-0.4.16.zip`，解压得到 `webdavmanga.koplugin`。完全退出 KOReader，备份原插件，复制整个文件夹至 `koreader/plugins/`，保留用户数据和设置目录；重启后“关于”应显示0.4.16。

同时安装 GrayDither 0.3.0 并启用插件；打开本来源漫画，确认两个开关起初关闭，单独开灰度后正文显示改变但不自动全刷。再单独开自动全刷，把间隔设为2，连续显示两个新阅读画面应执行所选全刷，重复设置/返回同一画面不计。检查象限、长条位置和分格自由视图移动/缩放；在加载、设置、休眠或退出时取消辅助阶段，关闭自动全刷后原页全刷/动画偏好恢复。

黑白辅助会闪屏。设备触控、真实波形、残影、保持时长及 CPU/内存峰值尚未验证，请先在自己的设备上比较原生全刷与黑白辅助。
