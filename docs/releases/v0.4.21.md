# WebDAV Manga v0.4.21 · 统一漫画插件背景

从主菜单直接进入 OPDS、连接/阅读/缓存设置、历史、分类架、评分架、缓存架或阅读指针时，先建立同一个不透明全屏插件背景。目录进入、返回、取消、异步等待和窗口交接都保留背景；明确退出时先关闭插件窗口，最后撤去背景，返回 KOReader。

Browser、OPDS 的输入、续读和提示弹窗，以及设置与分类架提示统一登记到已有窗口管理。退出会取消连接测试、待完成的密钥验证和整部漫画缓存任务，保留已缓存页面。过期的联网、授权或缓存结果不能再弹窗或重新恢复阅读；退出后可正常重新打开插件。后台返回不会误入上次保存的无关目录。

本版复用现有背景和窗口管理，无新增依赖，没有修改格式解析。保留 v0.4.20 的常见漫画文件封面及独立书架缓存。

安装：完全退出 KOReader，备份旧插件；解压 `webdavmanga.koplugin-v0.4.21-20261010-plugin-background.zip`，将完整 `webdavmanga.koplugin` 放入 `koreader/plugins/` 覆盖程序文件，保留设置和缓存。重启，在关于中确认 `0.4.21`。已有 GrayDither 0.3.1 无需重装。

验收：依次从主菜单打开 OPDS、连接设置、阅读设置、历史及各类书架，反复进入/返回目录、切换封面与列表、取消加载。期间应一直显示漫画插件背景；只有明确关闭插件才显示 KOReader。单独打开设置并关闭弹窗后，用背景返回键或右上角关闭退出。连接测试或密钥验证进行中退出再重开，旧结果不应重新弹窗。七份原文件逐本流式打开和翻页，不选择完整下载。
