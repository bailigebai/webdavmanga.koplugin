# WebDAV Manga v0.4.23 · 确认退出背景修复

修复右上角“关闭漫画插件 → 确认”后仍被全屏背景挡住、不能返回 KOReader 的问题。历史封面网格的取消返回值表示“是否原来打开过”；网格已经关闭时返回 false，退出流程误把它当成窗口关闭失败，因而一直保留背景。Browser 会先取消同一网格，controller 再次取消也触发这个问题。设备日志已确认相同调用链。

本版只调整 controller 对历史网格取消结果的理解，保留该操作的异常保护和其他真正关闭失败的重试能力。确认退出后关闭插件窗口，最后移除背景；取消确认继续留在书架；退出后可再次打开和退出。没有修改图像、分格、格式解析、缓存或连接设置，0.4.22 的三视图和对白优先功能继续保留。

安装：完全退出 KOReader，备份旧插件；解压 `webdavmanga.koplugin-v0.4.23-20261010-exit-background-fix.zip`，将完整 `webdavmanga.koplugin` 复制到 `koreader/plugins/` 覆盖程序文件，保留设置、授权、历史与缓存。完全重启，在关于确认 `0.4.23`。

验收：分别在列表和封面书架、根目录和子目录点右上角关闭，先取消应留在书架，再确认应回到 KOReader。重新打开插件后再次确认退出；阅读历史未打开或已经打开后关闭，两种情况下都应正常退出。目录加载中从背景关闭也应回到 KOReader。

验证：新增真实 Main + Browser + CoverGrid + Registry 组合测试先复现 RED，修复后 30 项检查通过；覆盖列表/封面、取消确认、已关闭与已打开历史、重复退出、退出后重开、注入的关闭失败和取消抛异常后的重试。8 组退出相关专项、209/209 组完整功能回归、112 个产品 Lua 语法及 6 个 Python 交付门槛通过。最终运行字节重新通过七份原文件 ARM 流式冷暖/EPUB 旧目录检查，303 张正文缓存图与额外 7 张书架首图完整像素解码，暖首图零 Range 请求。结构化报告见[原文件验证](../stream-formats-0423.json)及[验证记录](../verification.md)。
