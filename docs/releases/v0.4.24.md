# v0.4.24：独立动态面板变焦

新增“动态面板变焦”，与智能分格双向互斥。使用 KOReader 自带 Leptonica 即时检测当前页，面板居中并遮蔽相邻内容，预渲染下一格。与智能分格独立保存阅读顺序、聚焦边距、长按原图扩展与自由缩放倍率。

在漫画阅读设置或全局默认设置中开启，选择默认图片引擎和整页显示，长按进入。中央点按或两指轻敲打开动态控制；左右边缘点按和滑动依左到右/右到左顺序切格。面板中长按读取周边实际原图，原生缩放支持双指与拖动，关闭回原格；对白点击仍优先。未识别页整页显示，下一页继续检测。点按设置用于本书，长按同时作为新书默认。

稳定性处理：模式保存失败保留原格和位置；切模式、换页与退出使旧预加载无效；自由缩放迟到结果回收；原生窗口关闭失败时不释放仍被显示的图像，成功撤栈后仅释放一次。上一版插件背景确认退出修复保留。

验证：211/211 组功能回归、113 个 Lua 文件语法通过；动态专项45项；独立审计覆盖模式切换/失败/资源关闭顺序。真实 ARM LuaJIT、KOReader Blitbuffer/Leptonica 原生14组测试通过，66次原生分配均回收。七份原文件（两份RAR、EPUB、PDF、ZIP、7Z、AZW3）正文首/中/末页及书架首图流式门禁通过；不允许整本下载替代成功。

下载 `webdavmanga.koplugin-v0.4.24-20261010-dynamic-panel-zoom.zip` 和同名 `.sha256`。备份并覆盖 `koreader/plugins/webdavmanga.koplugin`，完全重启 KOReader，在关于确认0.4.24。设置、账号、授权、阅读进度与缓存不在包内。

本版为设备测试版。复杂/无框/连格准确率、真实触摸、墨水屏残影和性能仍需验收；预加载未完成仍可能短暂等待。未增加OCR或生成缺失文字。交互及原生API参考 [koreader-dynamic-panelzoom](https://github.com/JorgeTheFox/koreader-dynamic-panelzoom)，没有搬入其全局阅读器挂钩或新增二进制依赖。
