# v0.4.28：漫画书架封面加速与小图缓存

原来一张封面查目录、取图、生成和显示完毕后，才启动下一张。现在当前可见页最多六张完整链并行，缓存封面优先显示，慢卡片不挡住已经缓存的其他卡片。小容量缓存自动减少并发；正文预加载与阅读历史沿用原默认。

封面按卡片实际宽高生成完整等比小 PNG，硬上限384×512；尺寸进入缓存键，三列/五列或屏幕变化生成对应尺寸。以120×160卡片为例，缩略图像素为旧最大尺寸的约1/10；文件体积取决于画面，不能承诺所有文件同倍缩小。旧缓存按原容量与LRU策略回收；不改原始文件，不下载整本漫画。

各工作槽独立解析与取消，下载沿用现有去重和子进程回收；同一首图在多个卡片中只生成一次缩略图。目录、原始首图临时文件和PNG都受现有书架配额控制，不让第一个任务独占全部空闲预算。

PDF 原生封面先读页信息，再直接渲染小图，省去大 PNG 中转。EPUB 压缩目录的临时文件计入书架配额，取消后等子进程回收再清除；修改配额立即调整并发和临时预算。缓存命中、并行乱序、翻页取消、小容量和预算等待均有回归检查。

验证、限制与交付证据见[验证记录](../verification.md)。固定2秒目录+2秒传输的15卡受控模型：修改前60秒，修改后12秒，5倍；这是调度模型，实际Kindle/Wi-Fi/服务器/图片解码/屏幕耗时仍需实测。

真实KOReader ARM小图测试：样本JPEG 382353字节，小卡片PNG 12554字节；三种尺寸全像素解码、原图不变、暖缓存零源请求。完整功能220组、113个Lua语法、6个发布契约检查及七份原文件流式门禁通过。不是所有图片压缩率或实机速度的承诺。

验收：完全重启KOReader，在关于确认0.4.28。打开相同15张封面的目录，记录从进入到全部封面出现的时间；再次返回同页应直接显示缓存封面。切换三列/五列，检查清晰度与独立缓存占用；加载中翻页、进入/返回、切连接和确认退出，不应出现旧封面、露出KOReader或无法退出。再测试两份RAR、EPUB、PDF、ZIP、7Z、AZW3的正常流式阅读。
