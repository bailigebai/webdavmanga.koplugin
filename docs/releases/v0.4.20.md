# WebDAV Manga v0.4.20 · 书架背景与漫画文件封面

进入目录、返回上级、切换视图及等待请求期间，书架底下保留一个全屏插件背景。退出时取消目录、封面及排队的导航动作，旧请求不能重新打开菜单；等待或失败时仍可返回。

封面顺序：先取当前目录按数字自然排序的散装图片，没有图片时读取当前目录漫画文件的第一张阅读图片，再查下一层。文档目录在封面模式中显示每本书的卡片。支持 ZIP/CBZ、RAR/CBR、7Z/CB7、TAR/CBT、图片 EPUB、MOBI/AZW/AZW3/PRC、受当前解析器支持的图片 PDF。ZIP/TAR 按自然排序，EPUB 按书籍页序，RAR/7Z 沿用正文流式页序。

页面描述和缩略图继续使用独立“漫画书架封面缓存”，保留现有容量、清理和断网浏览规则；新索引绕过旧的“无封面”记录，不要求清空全部缓存。只加载当前屏幕的封面，不为封面静默下载整本。取消或超时的原生 PDF 临时图等待进程回收后清理。

加密、损坏或不支持的文件保留占位卡，仍可点击进入原有阅读流程。复杂远程 PDF 需要设备 MuPDF 远程读取能力；本版没有新增解码库，不保证所有文档变种。完整下载后的 PDF 正文阅读保留原流程。

安装：完全退出 KOReader，备份旧插件；解压 `webdavmanga.koplugin-v0.4.20-20261009-bookshelf-document-covers.zip`，把完整 `webdavmanga.koplugin` 放入 `koreader/plugins/` 覆盖程序文件，保留设置和缓存。重启，在关于中确认 `0.4.20`。已有 GrayDither 0.3.1 无需重装。

验收：切换封面模式，进入和返回多个文件夹、快速退出，检查不露出原生界面、不重开旧窗口；进入电子书测试目录检查各本封面，重开后仍显示；逐个打开七份原文件，不选完整下载，检查首页、翻页与末页。缓存过时可用书架“刷新”重新选图。

电脑未检测到 Kindle，本版没有实机安装。真实触摸、墨水屏、Wi-Fi 和服务器行为待设备验收；自动化使用严格 Range、调度和窗口替身，测试范围见[交付检查](../stream-formats.md)。
