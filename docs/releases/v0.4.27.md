# v0.4.27：页面自动裁剪增强

在“漫画阅读设置 → 裁切白边”同时开启“自动裁白边”和新增“页面自动裁剪增强”。增强默认关闭，是独立算法选项；关闭总开关后不运行，关闭增强则回到原自动裁边算法。

本次改动：

- 使用连通区域过滤页边扫描细框和孤立杂点，合并正文后向外留白；保留伸到页边的实际图画与对白，暗页、满版、空白或超出安全上限时保留整页。
- 增加页边细线宽度0～10（默认2）、最小内容面积1～100（默认4）、额外留白0～5%（默认1%）。前两项以最长边320像素的分析图计量；留白按原图尺寸计算，另有一采样格保护。复用原强度与每侧0～30%最大裁切限制。
- 参数进入预处理缓存键，预加载和显示共用结果，同页重绘不重新分析；原文件缓存继续复用。关闭去灰和亮度/对比度后，裁边不单独显示“处理图像成功”。
- 修正长条阅读中修改增强、留白及原自动裁边设置不生效的问题；重新处理当前源图，保留滚动位置，取消旧任务，忽略迟到回调。
- 保留原图像素与缓冲所有权，没有新依赖或 KOReader 全局文档/面板钩子。设置校验及保存失败沿用既有事务回滚。

参考 [Crop Enhancer](https://github.com/tachibana-shin/crop_enhancer.koplugin) 提交 `2121319c8cce01f07cb9521d0d5b38a75da87735`（MPL-2.0）的连通区域思路，独立实现；本插件使用有界 Lua 图片分析，未复制参考源码或移植其 KOPTContext 全局替换。

安装：下载本页 `webdavmanga.koplugin-v0.4.27-20261010-crop-enhancer.zip` 和同名 `.sha256`，完全退出 KOReader，备份原插件后覆盖 `koreader/plugins/webdavmanga.koplugin`。保留 settings 和授权文件，重启确认版本 **0.4.27**。

验收：

1. 开启两个裁边开关，用默认增强参数打开有细扫描框/杂点的漫画；检查正文和对白完整。关闭增强，比较原裁边；关闭总开关，应恢复原图。
2. 调整额外留白，检查当前页变化；切换到长条模式，滚动到中间再调整，检查位置保持和当前图片更新。
3. 用浅色、细小对白及满版/暗页检查完整性。采样不能保证识别所有细节；若误裁，增留白、降低最小内容面积或关闭增强查看原图。
4. 分别验证测试目录的两份RAR、EPUB、PDF、ZIP、7Z、AZW3首屏与翻页，再检查象限/对白/分格、列表/封面书架和确认退出到KOReader。

触摸、真实服务器与墨水屏效果仍需设备验收。本机同步保留与GitHub相同的安装ZIP，验证证据见 `docs/verification.md` 与 `docs/stream-formats-0427.json`。
